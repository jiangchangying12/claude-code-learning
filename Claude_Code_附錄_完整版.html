服務設定、Anthropic 概要與法務規約

附錄涵蓋：Amazon Bedrock 與 GitHub CLI 的設定步驟，以及使用 Claude Code 時該理解的 Anthropic 公司概要、合規作為與契約規約。以下為 2025 年 11 月時點資訊、不含法律建議，正式導入請看官方最新文件並諮詢法務/律師。

A.1　在 Amazon Bedrock 上使用 Claude Code

export AWS_ACCESS_KEY_ID=...        # AWS 金鑰
export AWS_SECRET_ACCESS_KEY=...
export CLAUDE_CODE_USE_BEDROCK=1   # 改走 Bedrock
export AWS_REGION=ap-northeast-1   # 東京區域
export ANTHROPIC_MODEL='jp.anthropic.claude-sonnet-4-5-20250929-v1:0'

以 /status 確認 API provider: AWS Bedrock。經 Bedrock 使用時，模型存取的準據法與管轄依「客戶↔AWS」契約（日本企業可選日本法）；且 Bedrock 標準政策明載客戶資料不用於模型訓練、可指定模型所在區域。

A.2　GitHub CLI 的驗證

gh auth login
# → 選 GitHub.com → HTTPS → 用憑證驗證 → Login with a web browser
# → 複製一次性代碼，在瀏覽器登入並輸入 → ✅ Authentication complete.

B.1　Anthropic 概要、合規與法務

公司概要

Anthropic 是 PBC（Public Benefit Corporation，公益法人）：依美國德拉瓦州法，章程載明同時追求營利與公共利益。2021 年由含前 OpenAI 成員的 7 人創立，使命含「為人類長期利益、負責任地開發先進 AI」。在企業 LLM API 市佔 32%、開發者程式碼生成市佔 42% 皆居首。

合規（第三方認證）

  • SOC 2 Type II：驗證一定期間實際運作的有效性（較 Type I 嚴格）。
  • ISO/IEC 27001:2022：資訊安全管理國際規格。
  • GDPR 遵循（提供 DPA）、HIPAA 對應（需簽 BAA）、CCPA、PIPEDA、UK GDPR、APPI 等。

文件（SOC 2 報告、ISO 證書、DPA、滲透測試報告）可向 Trust Center（trust.anthropic.com）申請。

Usage Policy 主要禁止：選舉操弄、惡意電腦活動（malware/攻擊；經同意的正當滲透測試例外）、侵害隱私、政府審查、兒虐/暴力/武器/訓練競品模型；高風險用途（醫療/法律/財務/雇用決定）需「人在迴圈＋向使用者揭露 AI」。

🏢 資料管理與著作權重點 消費者方案：Anthropic 為資料控管者，適用其隱私政策；「協助改善 Claude」可開關，開啟時業務程式碼/提示可能被用於訓練，需注意。
Claude for Work（Team/Enterprise）：企業為控管者、Anthropic 為處理者（適用 DPA）——業務使用建議選 Team/Enterprise。
著作權：生成程式碼的權利在適用法範圍內歸使用者（消費者與商用方案皆然）。
IP 智財補償（生成物被控侵權時的法律/金錢支援）：僅商用方案適用，且總責任額可能受限於過去 12 個月實付費用。
