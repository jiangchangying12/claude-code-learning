Claude Code 的基礎：安裝與第一次使用

作者：大嶋勇樹。本章說明開始使用 Claude Code 所需的最低限度基礎：概要、收費方案、安裝設定、基本用法。Claude Code 由 Anthropic 提供，以 claude 指令在終端機啟動，邊對話邊寫程式。

2.1　概要與三種驗證方式

方式說明注意
Claude.ai 訂閱Pro / Max / Team / Enterprise本書動手實作用 Pro 就夠
Claude Console（API）API 金鑰、用量計費自動儲值可能無月上限

2.2　動手實作環境的建置

📦 為何用 Dev Container 直接裝在 macOS/Windows，Claude Code 有可能誤改/刪主機檔。本書在 Dev Container（隔離容器）做實作：與主機隔離、團隊共享一致環境。前提：已登入 GitHub、已裝 VS Code、Dev Container 擴充、Docker。

建立 GitHub 私有儲存庫（用範本）、複製到本機、code . 開啟，再用指令面板「Dev Containers: Reopen in Container」啟動容器。

2.3　安裝設定

curl -fsSL https://claude.ai/install.sh | bash
claude --version    # 顯示 Claude Code (2.0.37) 即成功

首次啟動 claude 會引導：選樣式（深/淺色）→ 選驗證方式（訂閱選「Claude account with subscription」）→ 瀏覽器授權 → 資安注意事項 → 信任目前資料夾 → 安裝 VS Code 擴充 → 完成、開始工作階段。/exit 或 Ctrl+C 結束；/logout、/login 可改驗證。

2.4　第一次使用 Claude Code

🧪 互動 vs 無頭模式 互動：claude 啟動，邊對話邊做。無頭：claude -p "請自我介紹" 一次指示、無對話完成並結束（CI/自動化基礎）。

示範：請它「用 index.html 和 main.js 實作打磚塊」，它會一次建立多檔，並在需要時請求許可（執行指令、寫檔）。也能讓它執行指令（npx http-server 起伺服器）、用 @檔名 參照檔案（「請解說 @main.js」）。

🎲 Vibe Coding完全憑感覺、甚至忘了程式碼存在的寫法叫 Vibe Coding。方便但品質不穩——第 4 章會看到它的坑與正解。

2.5　其他基本功能

斜線指令

指令用途
/clear清除對話歷史
/compact摘要對話歷史
/help顯示說明與可用指令
/init產生 CLAUDE.md
/resume重開工作階段
/exit結束
表 2.2　Claude Code 的斜線指令（部分）
🧠 CLAUDE.md ＝ Claude Code 的『記憶』 執行 /init 會調查程式碼庫、自動產生 CLAUDE.md，記錄專案規則與基礎知識。Claude Code 會自動讀取目前/上層目錄的 CLAUDE.md——它是後面規格驅動開發的核心。種類：專案共享、CLAUDE.local.md（個人）、~/.claude/CLAUDE.md（跨專案個人）。

計畫模式與重開工作階段

按 shift+tab 在「一般 → 自動編輯 → 計畫」三模式間切換；計畫模式讓 Claude Code 唯讀作業（只探索/規劃、不改檔）。claude --continue 或 /resume 可重開先前工作階段。

2.6　本章小結

✅ 重點Claude Code 是 CLI 型代理，用自然語言指示就能接連建檔、改檔、執行指令。光本章基本操作就能做出簡單 App。但要熟練運用，還需 MCP（第 3 章）與理解代理特性（第 6、7 章）。
